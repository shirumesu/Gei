# Current How-To

Use this reference for operational instructions that depend on a current product, platform, API, law, or service.

1. Identify the exact version, platform, account type, region, and prerequisites.
2. Prefer current official documentation for supported steps and interfaces.
3. Use community workarounds only when official guidance is missing or demonstrably insufficient; label their support and risk.
4. Give one executable main path, then only the alternatives needed for material variants.
5. Include a concrete check that confirms the intended result.

Call out destructive, irreversible, billable, or production-changing steps before they occur. Do not carry forward widely copied commands without verifying that they still match the current interface.
