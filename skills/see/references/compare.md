# Comparison

Use this reference when the user must choose among alternatives.

1. Recover the decision, constraints, budget, time horizon, and criteria that can change the choice.
2. Verify that each candidate and compared feature is current for the relevant region, version, or plan.
3. Use equivalent evidence for each candidate where possible; do not compare one vendor's marketing with another's independent test.
4. Separate hard requirements, meaningful tradeoffs, and preferences.
5. Recommend the best fit for the stated scenario, including cases where another candidate wins.

Do not force a single winner when the result depends on a genuine user preference or missing fact. Make uncertainty and switching cost visible when they affect the decision.
