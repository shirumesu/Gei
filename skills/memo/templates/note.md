# Searchable decision or symptom

Summary: conclusion and retrieval cue.
Status, if consequential: confirmed decision, proposal, observed behavior, or accepted but unimplemented. Prior recording alone does not establish acceptance.
Applies: relevant scope and conditions.

Reason: constraints, priorities, actual alternatives, and accepted cost; or verified pitfall cause and response. Label inferred reasons separately from confirmed ones.
Reconsider: changes that would invalidate this reasoning.
Evidence: the relevant authority; revision/environment only when significant. Omit fields that add no useful context.
